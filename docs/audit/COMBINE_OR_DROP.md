## Read this before ruling

- **Metrics differ.** H16/H17/H18 class percentages are changed 16-px blocks of
  the named class, not changed pixels or the whole window. The audit's **R** is
  `maxReferenceBlocksPct`, **D** is `maxOperatingBlocksPct` in diagnostic fixtures;
  both are from stale `c4b1b80` whole-window screening. `height`/`field` are its
  geometry maxima. A blank is unmeasured, not zero. Do not compare R/D directly
  with the cards' 5% class bar. A 0% block result can still contain visible thin marks.
- **Readers differ.** World numbers flow from `sculpt.py` defaults/world/engine/
  variant settings through renderer uniforms. Shape options flow from the stroke
  card through `sculpt-gpu-fields.js` and `engine-shape.wgsl`; H18's corrected
  probes set those cards. Query-only zeros do not retire stroke options. Per-stroke
  masks also override world shore/depth/bed choices.
- **Current-reference column is an index, not a deletion recipe.** For each CSV
  key it lists the first non-comment exact-key or `uCapitalizedKey` occurrence
  in each relevant runtime file; this can be plumbing rather than a final shader
  read. Generic persistence/dispatch and aliases are described here and in the
  counted recipes. Only the source-confirmed disconnected group claims no live
  consumer. Other rows explicitly retain the unresolved reachability question.
- **Count method:** physical lines, inclusive spans, including comments within
  a removed block; a modified expression on a surviving line saves zero. Code
  bundles and their individual knobs are cross-referenced, not counted twice.
  The 214-line generator is development tooling, not runtime shader code; the
  image byte size is separate and not converted into lines.
- **World column:** explicit current world/variant settings are named where
  possible; all other worlds inherit defaults. These names do not limit a
  feature's authoring scope. CSV-only world names describe the old measured
  reference set. A preset value of zero is never by itself called dead code.
- **Decision column is advisory.** `merge` requires a shorter implementation
  and target evidence before removal; `keep` can mean the current evidence is
  insufficient. Bodies and Impacts should update/add rows using the same columns.

1. **H16 coast zeros were query false negatives.** H18 stroke-card probes show
   `layerVary` 10.6%, `lavaSpread` 8.7%, `lavaCircleVary` 15%, `layerCircle` 26.7%,
   `layerRiser` 33.1%, `layerStyle` 23%. `layerLedge`, `layerRough`, `lavaMeander`
   still move pixels (.35/.50/1.58 MAD) despite remaining under the class bar.
2. **`columnContrast` is measured and acts.** H16's coordinator supersedes the
   old H5 under 5% and H16 unmeasured list: Green 8.0/4.7/5.9%. H16's proposed
   drops of `ringLobe`/`ringPatchSize` also conflicted with 10%/21% evidence.
3. **H17's “every probe” weak list overstates its table.** Part 1 gives Ice
   `crackHairline` 12.3% and `crackBlocks` 5.8%; wider probes give `facetStep` 9.3%,
   `blockTilt` 31.4%, `blockStep` 16.4%, `blockSeam` 58.9%. Moon `crackSeverity`
   is 43.4% at a wider probe even though part 3's desired fissure was not visible.
4. **No beach in 27 scenes is not no beach.** Zhon's scenes override width 0;
   its new-map default is .6 and the on probe reaches 53.7% class. `apron` and
   `sandCrown` act too. H18's old 82-line sketch counts `beachColour/Mean/Sand`
   as 9+8+6; they are now one line each. `beachCover` is 39 and the draw block 10.
   Other readers still need reconciliation; no net beach total is claimed.
5. **No new coast flood is approved.** H18's coordinator rejected the ~40-line
   saving because it omitted replacement code and would leave two distance fields.
6. **`bandWater` is not proved dead in all worlds.** Green's sharp step ignores
   its `colorDepth`; the ordinary ramp still consumes that value. `hardDeepStep`
   is also selectable through local `waterDeep` when `stepSharp` is 0.
7. **H18's marks total is not 27 deletable lines.** The eight named marks yield
   **22 counted lines** here: rag 10 + dots 10 + grain 1 + crackedContrast 1.
   Dither, softness, threshold selects and crack-slope input are edits on lines
   that remain. Mottle is counted separately at 7 lines. At final main mottle
   is 0 in **every** world, not merely dead in Archipelago. Dither defaults to 1,
   with 0 explicitly set in the three lit-bed worlds.
8. **H17's joint-shift ~8 lines is stale.** Its shift is now part of a one-line
   `jointFieldAt` return; zero net removal is credited without a concrete rewrite.
   `fractureDepth` is 19 physical lines (not ~18). Its only call is unreachable
   from the bake; the generated `fracturedSource` material layer is a different
   source and must not be removed with `fractures.png`.
9. **Old names can still be live.** Flow tint/bank keys absent from
   `KNOB_DEFAULTS` are read in `sculpt-renderer.js:964-968`. `bandSpacing` and
   `bandLine` stopped being scalar controls but remain derived uniforms. H16
   options `vary`, `ledges`, `wander.erosion` were removed in review, not current
   panel options. The table has **28** names outside KNOB_DEFAULTS; not all are dead.

does not mean removing unrelated labels (`rock`, `noise`) or the live weather UI.

(`sculpt.py:777-803`); the page copies the result into query defaults
(`sculpt.js:1622-1625`), so registration absence alone is never the test.
